Everyone is using AI, from developers to HR. And as agents become part of everyday work, we're giving them skills: reusable instructions that teach an agent how to perform tasks, use tools, access systems, and execute multi-step workflows. Installing an AI skill is a lot like installing a browser extension: it may promise one useful capability, but you still need to know who built it, what permissions it gets, and what it can do once it's running.
